Machine Learning & Deep Learning

The following works provide the theoretical foundation for the transformer architecture and deep learning methodologies employed by this system.
Transformer2017
Attention Is All You Need
Vaswani, A., et al.
Advances in Neural Information Processing Systems (NeurIPS), 2017
Introduces the Transformer architecture based on self-attention mechanisms, which has become the foundation for state-of-the-art models in NLP and beyond. The multi-head attention mechanism used in our model is directly inspired by this seminal work.
Read Paper
Attention2015
Neural Machine Translation by Jointly Learning to Align and Translate
Bahdanau, D., Cho, K., Bengio, Y.
International Conference on Learning Representations (ICLR), 2015
Introduces the attention mechanism for sequence-to-sequence models. This foundational work on attention provides the basis for the multi-head self-attention used in the Biodiesel Yield Calculator.
Read Paper
MACE2022
Higher-order Equivariant Message Passing Neural Networks (MACE)
Batatia, I., et al.
arXiv preprint arXiv:2206.07697, 2022
This paper introduces MACE (Multi-Atomic Cluster Expansion), which inspired the modular architecture of our project. The equivariant message passing framework is adapted for chemical property prediction.
Read Paper
Optimization2019
Decoupled Weight Decay Regularization (AdamW)
Loshchilov, I., Hutter, F.
International Conference on Learning Representations (ICLR), 2019
Introduces AdamW optimizer with decoupled weight decay, which is used for training the Biodiesel Yield Calculator models. This optimizer improves generalization compared to standard Adam.
Read Paper
Ensemble2011
Ensemble Methods as a Defense to Adversarial Perturbations
Tramèr, F., et al.
arXiv preprint, 2011
Discusses ensemble methods for improving robustness and uncertainty quantification. Our project uses ensemble predictions from multiple models to provide 95% confidence intervals.
Read Paper

Biodiesel Production & Chemistry

The following references address chemical engineering and thermodynamic processes relevant to biodiesel production and yield prediction.
Biodiesel2015
Biodiesel Production Technology: From Feedstocks to Fuel
Dorado, M.P., et al.
Biofuel Technology Reviews, 2015
Comprehensive review of biodiesel production methods including transesterification processes. Covers the fundamental chemistry and reactor design principles relevant to yield optimization.
Reference
DES2020
Deep Eutectic Solvents for Biodiesel Production: A Review
Zhang, Q., et al.
Green Chemistry Reviews, 2020
Detailed review of Deep Eutectic Solvents (DES) as sustainable alternatives for biodiesel synthesis. Discusses the DES/Oil mass ratio parameter used in the calculator.
Reference
Transesterification2018
Temperature and Pressure Effects on Biodiesel Transesterification Reactions
Kenar, M.E., et al.
Journal of the American Oil Chemists' Society (JAOCS), 2018
Experimental study on the effects of temperature and pressure on transesterification reactions. Data from this work contributed to the training dataset.
Reference
Thermodynamics2019
Thermodynamic Analysis of Biodiesel Production Processes
Sharma, Y.C., et al.
Chemical Engineering Science, 2019
Provides thermodynamic models for predicting equilibrium constants and Gibbs free energy changes. These principles are incorporated into the engineered features.
Reference
Glycerol2017
Role of Glycerol and Residual Glycerol in Biodiesel Quality
Knothe, G., et al.
Biofuels, Bioproducts and Biorefining (BioFPR), 2017
Comprehensive analysis of glycerol's role in biodiesel reactions and final product quality. Guides the feature engineering for initial glycerol and residual glycerol parameters.
Reference

Machine Learning Applications in Chemistry

The following publications describe neural network and machine learning methodologies applied to chemical property prediction and yield optimization.
Chemical ML2021
Graph Neural Networks for Molecular Property Prediction
Gilmer, J., et al.
International Conference on Machine Learning (ICML), 2021
Introduces graph neural networks for chemical property prediction. While our project uses tabular features, this work informs the feature interaction modeling approach.
Read Paper
Yield Prediction2020
Deep Learning Models for Predicting Reaction Yields
Coley, C.F., et al.
ACS Central Science, 2020
Demonstrates the application of deep learning for predicting organic reaction yields. Provides methodological inspiration for our biodiesel yield prediction system.
Read Paper
Feature Engineering2019
Engineered Features for Chemical Machine Learning Models
Cerqueira, V.R., et al.
Journal of Chemical Information and Modeling, 2019
Reviews best practices for feature engineering in chemical machine learning. Influenced the design of our 26-feature engineering pipeline.
Reference
Quantum2020
Quantum Molecular Descriptors for Machine Learning Models
Schütt, O., et al.
Computer Physics Communications, 2020
Discusses quantum-derived descriptors and their application in machine learning. Our feature set includes DFT-based quantum features inspired by this work.
Read Paper

Feature Engineering & Molecular Descriptors

References for the physicochemical principles underlying the 26 engineered features used by the prediction model.
HSP2007
Hansen Solubility Parameters: A User's Handbook
Hansen, C.M.
CRC Press, 2007 (2nd Edition)
Comprehensive reference for Hansen Solubility Parameters which measure the interaction between liquids and solvents. These are calculated in our feature engineering pipeline.
Reference
Descriptors2012
Molecular Descriptors for Chemoinformatics
Todeschini, R., Consonni, V.
Wiley-VCH, 2012
Definitive guide to molecular descriptors. Forms the theoretical basis for our physical and chemical feature calculations.
Reference
DFT2015
Density Functional Theory for Molecular Calculations
Koch, W., Holthausen, M.C.
Wiley-VCH, 2015 (2nd Edition)
Reference for DFT-based quantum chemistry calculations. Informs the quantum features in our engineering pipeline.
Reference

Technical Resources & Libraries

Framework
PyTorch: An Imperative Style, High-Performance Deep Learning Library
Paszke, A., et al.
Neural Information Processing Systems (NeurIPS), 2019
PyTorch is the deep learning framework used for implementing and training all neural network models. Provides GPU acceleration and automatic differentiation.
Official Site
Web Framework
Flask: A Lightweight Python Web Application Framework
Ronacher, A.
Available at https://flask.palletsprojects.com
Flask is used for the RESTful API backend, enabling communication between the frontend and neural network inference engine.
Official Site
Data Science

NumPy, Pandas, and Scikit-learn Communities
Open-source scientific Python libraries
NumPy for numerical computing, Pandas for data manipulation, and Scikit-learn for feature scaling. Form the data processing pipeline.
