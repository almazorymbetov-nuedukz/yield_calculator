Machine Learning & Deep Learning

The following works provide the theoretical foundation for the transformer architecture and deep learning methodologies employed by this system.
Transformer2017
Attention Is All You Need
Vaswani, A., et al.
Advances in Neural Information Processing Systems (NeurIPS), 2017
Introduces the Transformer architecture based on self-attention mechanisms, which has become the foundation for state-of-the-art models in NLP and beyond.
Read Paper
Attention2015
Neural Machine Translation by Jointly Learning to Align and Translate
Bahdanau, D., Cho, K., Bengio, Y.
International Conference on Learning Representations (ICLR), 2015
Introduces the attention mechanism for sequence-to-sequence models. This foundational work on attention provides the basis for the multi-head self-attention used in the Biodiesel Yield Calculator.
Read Paper
