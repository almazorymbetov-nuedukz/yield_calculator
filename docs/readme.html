Project Overview

The Biodiesel Yield Calculator is an advanced machine learning system designed to predict biodiesel yields in transesterification reactions. It utilizes a transformer-based neural network architecture with 26 engineered features to provide accurate predictions with uncertainty quantification.

The system is implemented as a modular architecture inspired by Multi-Atomic Cluster Expansion (MACE), employing advanced deep learning techniques for biodiesel yield prediction.

Machine Learning Algorithms

1. Transformer Architecture (Recommended)

The primary model is based on a transformer architecture, which captures complex feature interactions more effectively than conventional feedforward neural networks.

Key Components:
  • Multi-Head Self-Attention: 8 parallel attention heads allowing the model to focus on different feature relationships simultaneously
  • Position Embeddings: Encodes feature positions to preserve order information
  • Feed-Forward Networks: GeLU activation functions for non-linearity
  • Layer Normalization: Stabilizes training and accelerates convergence

2. Feature Engineering Pipeline

The system extracts 26 engineered features from 7 input parameters using domain knowledge from chemistry and physics:

Feature Categories:
  • Thermodynamic Features: Temperature-dependent Gibbs free energy, equilibrium approximations
  • Hansen Solubility Parameters: Polar/nonpolar interactions between reactants
  • Quantum Chemistry Features: DFT-based formation energies and band gaps
  • Interaction Indices: Density-viscosity products, temperature-normalized ratios
  • Stability Indices: Glycerol stability, water interaction parameters
