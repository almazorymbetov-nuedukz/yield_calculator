Project Overview

The Biodiesel Yield Calculator is an advanced machine learning system designed to predict biodiesel yields in transesterification reactions. It utilizes a transformer-based neural network architecture with 26 engineered features to provide accurate predictions with uncertainty quantification.

This project represents a complete restructuring of the original yield prediction system, implementing a modular architecture inspired by MACE (Multi-Atomic Cluster Expansion) with state-of-the-art deep learning techniques.

🧠 Machine Learning Algorithms

1. Transformer Architecture (Recommended)

The primary model uses a transformer-based architecture, which has proven superior to traditional neural networks for capturing complex feature interactions.

Key Components:
  • Multi-Head Self-Attention: 8 parallel attention heads allowing the model to focus on different feature relationships simultaneously
  • Position Embeddings: Encodes feature positions to preserve order information
  • Feed-Forward Networks: GeLU activation functions for non-linearity
  • Layer Normalization: Stabilizes training and accelerates convergence

2. Feature Engineering Pipeline

The system extracts 26 engineered features from 7 input parameters using domain knowledge from chemistry and physics:

Feature Categories:
  • Thermodynamic Features: Temperature-dependent Gibbs free energy, equilibrium approximations
  • Hansen Solubility Parameters: Polar/nonpolar interactions between reactants
  • Quantum Chemistry Features: DFT-based formation energies and band gaps
  • Interaction Indices: Density-viscosity products, temperature-normalized ratios
  • Stability Indices: Glycerol stability, water interaction parameters

3. Training Strategy

  • Optimizer: AdamW with weight decay (L2 regularization)
  • Loss Function: Mean Squared Error (MSE)
  • Early Stopping: Monitors validation loss with patience=50 epochs
  • Learning Rate: Adaptive scheduling with initial rate of 0.001
  • Batch Size: 32 samples per batch for stable gradient estimates

4. Uncertainty Quantification

The system provides 95% confidence intervals using ensemble predictions from multiple model variants:

Ensemble Method:
  • Combines 3 independently trained transformer models
  • Mean prediction from ensemble = final yield estimate
  • Standard deviation × 1.96 = 95% confidence interval
  • Captures model uncertainty from random initialization and batch variation

🚀 Usage Guide

Web Interface

  1. Open index.html in your web browser
  2. Enter reaction parameters (Temperature, Molar Ratio, Density, etc.)
  3. Click "Calculate Yield" to get predictions
  4. Results show predicted yield with 95% confidence intervals

Python API

from yield_calc.calculators import YieldCalculator # Load the trained model calc = YieldCalculator("checkpoints/yield_model_attention.pt", model_type="attention") # Make a prediction result = calc.predict( t=313.15, # Temperature (K) r=1.5, # Molar ratio d=1.18, # Density (g/cm³) v=300, # Viscosity (mPa·s) m=0.1, # DES/Oil mass ratio w=0.5, # Water (%) g=1.5 # Initial glycerol (%) ) print(f"Yield: {result['yield']:.2f}% (±{result['yield_ci_95']:.2f}%)")
